# Impeccable Design Memory — WebsiteTekkom / Capstone (SICATA)

## Design Context

### Users
Admin, dosen, and mahasiswa share one Capstone shell for the full TA lifecycle (periods, groups, titles marketplace, bidding, documents, schedules, expo, evaluations, reports). Admin operators do long setup/monitoring sessions; dosen review/mentor between classes; mahasiswa complete gated step-by-step flows. Job to be done: finish the task without getting lost — clarity first, same shell for all roles.

### Brand Personality
Institutional, calm, trustworthy. Three words: clear, calm, consistent. Voice is formal academic Indonesian/English mix, never playful. Emotional goal: confidence during long admin workflows and gated student flows.

### Aesthetic Direction
Match SITKOM superadmin exactly (white sidebar, navy `#0B266E`/hover `#091958`, `Inter Tight` + `Geist` brand, section labels, `8px` rhythm). Minimal and technical, not bold/playful/organic. Both light and dark via existing `theme.css` tokens — reuse `.dark`, never invent new dark values. UNDIP blues required; no indigo/blue/gray Tailwind scale forks, no off-brand hex like `#2f3d8a`. Anti-reference: dense multi-scroll pages, `32px` page titles, `hover:scale` cards, raw `<dialog>`/FontAwesome/per-page SVGs.

### Design Principles
1. Match SITKOM, don't fork it — same widths (sidebar 240/64px, topbar 60px), padding (content 24/28/48), radii, and interaction rhythm.
2. Scannable over dense — section labels + `h-8` rows, one scroll container, card-in-page (`rounded-xl border shadow-small`).
3. Tokens only — `bg-primary/border/text-muted-foreground/bg-card/bg-muted`, semantic pairs (success/warning/error/sky); 16px row icons from the canonical Lucide map.
4. Forgiving states — disabled explains why via `title`/`aria-disabled`, toasts `aria-live`, focus-visible rings, `prefers-reduced-motion` fallback, 80px mobile bottom-nav clearance.
